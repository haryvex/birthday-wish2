# Interactive Birthday Gift

Open `index.html` to view. Add your song as `music/song.mp3` (it starts on the first tap).

Change the name shown: open the page with `?name=Priya` at the end of the link.

## Put it live with GitHub Pages
1. Create a new repository on GitHub and upload everything in this folder.
2. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main` / `(root)` -> Save.
3. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
